# Globe data

`globe-land.json` contains sampled latitude/longitude pairs from the public-domain Natural Earth land dataset distributed by `world-atlas` (land-110m).

Source: https://github.com/topojson/world-atlas
Natural Earth data: https://www.naturalearthdata.com/about/terms-of-use/

The points provide an illustrative geographic outline. The animated connections represent STACK-K learning concepts, not actual offices, customers, or service availability.
